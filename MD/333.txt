# 任务目标
你是一名 DevOps/后端开发专家。请帮我在服务器上部署 search-stack（AI Agent 专用的 Web 搜索与抓取中间层），并完成与现有 TypeScript 后端的集成。

# 背景信息
- 我的技术栈：TypeScript + Node.js 后端
- 我已部署 SearXNG（自托管元搜索引擎）
- 目标：让后端能够通过 API 调用实现「搜索招聘信息 → 自动抓取完整正文」的能力

# 部署要求

## 1. 环境准备
- 确保服务器已安装 Docker 和 Docker Compose
- 克隆仓库：`git clone https://github.com/rikouu/search-stack.git`
- 进入项目目录

## 2. 配置 SearXNG
- 由于我已部署 SearXNG，需要在 docker-compose.yml 中配置 SEARXNG_URL 环境变量指向我的 SearXNG 实例
- 如果尚未部署，使用项目自带的 SearXNG 容器（默认配置即可）

## 3. 启动服务
- 执行 `docker-compose up -d` 一键启动全部 4 个容器：
  - search-proxy（FastAPI 核心代理，端口默认 8000）
  - Redis（缓存 + 限流）
  - SearXNG（元搜索引擎，端口默认 8080）
  - Browserless（无头 Chrome，端口默认 3000）
- 验证所有容器正常运行：`docker ps`

## 4. API 鉴权配置（可选但推荐）
- 在 docker-compose.yml 或 .env 中设置 API_KEY 环境变量
- 生产环境务必启用 API Key 鉴权

## 5. 验证部署
- 测试搜索接口：
  ```bash
  curl -X POST http://localhost:8000/search \
    -H "Content-Type: application/json" \
    -H "X-API-Key: your-api-key" \
    -d '{"q": "软件工程师 北京", "engines": ["searxng"]}'
测试搜索+抓取一体化（enrich=true）：

bash
curl -X POST http://localhost:8000/search \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{"q": "软件工程师 北京", "enrich": true, "engines": ["searxng"]}'
测试单独抓取：

bash
curl -X POST http://localhost:8000/fetch \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-api-key" \
  -d '{"url": "https://example.com/job-detail"}'
TypeScript 后端集成要求
1. 创建 API 客户端模块
在 TypeScript 后端中创建 src/services/searchStack.ts，封装以下方法：

search(query, options)：调用 /search 接口

searchWithEnrich(query, options)：调用 /search 接口并启用 enrich=true

fetch(url)：调用 /fetch 接口抓取单页内容

manageCookie(action, data)：调用 Cookie 管理 API（如需登录态）

2. 配置管理
通过环境变量管理 search-stack 服务地址和 API Key：

text
SEARCH_STACK_URL=http://localhost:8000
SEARCH_STACK_API_KEY=your-api-key
3. 错误处理
实现重试机制（引擎 fallback 由 search-stack 自动处理，但网络层面需重试）

实现超时控制（建议 30 秒）

实现日志记录

4. 与现有业务集成
将 search-stack 作为招聘信息抓取的数据源，替换或补充现有方案

设计统一的数据结构，将抓取结果映射为业务实体

可选高级功能（按需实施）
Cookie 管理（如需抓取需登录的招聘网站）
使用 Cookie Catcher Web UI（挑选一个不会冲突的端口）完成登录

或通过 API 手动注入 Cookie

参考文档：https://github.com/rikouu/search-stack#cookie-management

多引擎配置
如需使用 Tavily 或 Serper，在环境变量中配置对应的 API Key

引擎 fallback 优先级：TAVILY_API_KEY → SERPER_API_KEY → SEARXNG_URL

MCP Server 集成（如需对接 AI 平台）
search-stack 支持 MCP Server 模式，可通过 mcporter 注册

如使用 OpenClaw、Dify 等平台，可配置 MCP 集成
