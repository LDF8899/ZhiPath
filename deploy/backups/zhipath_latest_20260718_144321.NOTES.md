## 导出命令

导出在 Docker 容器内完成，再复制到本机，避免 Windows PowerShell 重定向导致 SQL 编码异常。

```powershell
docker exec mysql sh -lc "mysqldump --default-character-set=utf8mb4 --single-transaction --routines --triggers --events --hex-blob --set-gtid-purged=OFF -uroot -proot123 --databases zhipath > /tmp/zhipath_latest_20260718_144321.sql"
docker cp "mysql:/tmp/zhipath_latest_20260718_144321.sql" "D:\ZhiPath\deploy\backups\zhipath_latest_20260718_144321.sql"
```

## 恢复命令

恢复前确认目标库可以被覆盖。该 SQL 使用 `--databases zhipath` 导出，包含 `CREATE DATABASE` 与 `USE zhipath`。

```powershell
docker cp "D:\ZhiPath\deploy\backups\zhipath_latest_20260718_144321.sql" mysql:/tmp/zhipath_latest_20260718_144321.sql
docker exec mysql sh -lc "mysql --default-character-set=utf8mb4 -uroot -proot123 < /tmp/zhipath_latest_20260718_144321.sql"
```

如果使用本机 mysql client：

```powershell
mysql --default-character-set=utf8mb4 -h127.0.0.1 -P3307 -uroot -proot123 < D:\ZhiPath\deploy\backups\zhipath_latest_20260718_144321.sql
```
